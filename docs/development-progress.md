## 验证范围

`mvnw clean verify` 执行编译与快速测试；Windows 使用 `mvnw.cmd`。C01–C04 包含 154 项测试；C05 新增 12 项存储测试。`mvnw -pl examples -am verify` 验证存储模块及依赖，共 115 项测试。已有测试，覆盖规范编码、流与配额边界、独立 Merkle 根、标准 HPKE 向量、帧篡改、真实 mTLS 及 HTTP 限制。

- V01：编码与长度边界已验证。
- V02：按序 Merkle 承诺已验证，包括非二次幂树和字段变化。
- V03：api/core 依赖边界已验证。
- V04：标准 HPKE Auth 向量及项目 info/AAD/frame 认证已验证。
- V05：证书、节点、路由、密钥及冻结 SPKI 的认证边界已验证；与持久写入结合的验收仍待后续阶段。
- V06：Open 编码、身份绑定与初始期限校验已实现；持久接纳、重放和冲突恢复尚未实现。
- V10：输入侧空流、短读、未知长度和末块已验证；端到端传输尚未实现。

V07–V09 的存储部分已覆盖，见[文件持久化](storage.md)。实际进程退出恢复及端到端验收尚未完成。当前组件不能作为完整安全传输系统部署；持久 ACK 已实现，认证传输与输出重读将在后续阶段装配。研究目标尚无性能收益结论。
