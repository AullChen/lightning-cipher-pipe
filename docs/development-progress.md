## 验证范围

`mvnw clean verify` 执行编译与快速测试；Windows 使用 `mvnw.cmd`。协议测试包含 81 项案例，覆盖最短编码、字段类型、长度溢出、尾随数据、短读及分配大正文之前的边界检查。

V01（编码边界）和 V03（依赖边界）已验证。V06 仅完成 Open 编码部分；重放、冲突、期限和持久接纳尚未实现。其他安全、持久化、恢复及性能验收尚未完成。

合成帧仅验证字节布局，不是 HPKE 密码向量。当前实现不能用于端到端安全传输；持久 ACK、输出重读、恢复和反馈调度将在后续阶段加入。
